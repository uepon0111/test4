# EQ 試聴用サンプル音源

このフォルダに、外部で取得したフリー音源を置くと、イコライザの試聴で使われます。

おすすめの置き方:
- `sample.mp3` … 1つだけ置けば、全モードの試聴で使えます。
- `sample-full.mp3` / `sample-bass.mp3` / `sample-melody.mp3` / `sample-chord.mp3` / `sample-drum.mp3` … モード別に置くと、それぞれ別の音源を再生できます。
- `.ogg` も同じ名前で置けます。例: `sample.mp3` がなければ `sample.ogg` を参照します。

GitHub Pages で配信する場合は、リポジトリ内のこの場所にそのまま配置してください。
