# 鉄道シミュレーター

zip を展開し、**フォルダ構成を保ったまま** `index.html` をブラウザで開いてください(サーバー不要)。

## 編集するときの注意
- JS は通常の `<script>` として、`index.html` に書かれた順に読み込みます。ファイル間で変数・関数をグローバルに共有しているため、**読み込み順を入れ替えない**でください。
- ES Modules(`import`/`export`)に変えると、ファイルを直接開いたときに動かなくなります。
- ファイルを追加するときは、`index.html` の `<script>` を、依存先より後ろに追加してください。
- 元の `index.html` のコードは、行を分けただけで1文字も変更していません(動作は元と同一です)。

## 追加機能
- **列車の編成**: 「列車」→「ダイヤ設定」の「編成」で1〜12両 (1両=20m=4マス)。「追加」タブでは、次に置く列車の編成を決められます。複製した列車は親の編成を引き継ぎます (個別に変更も可)。列車の位置は編成の中心で、駅では編成の中心がホームの中央に止まります
- **ホームの長さ**: 駅を選ぶと、番線ごとに「長さ」(2〜10両分) を設定できます。島式ホームは両側の番線で同じ長さになります。長さに応じて屋根・階段・照明の配置が変わり、白い目印は1両(20m)ごとの乗車位置です。長いホームは本線や並行する線路が自動で延びます (空きがないときは延ばせません)
- 保存データ: 列車の `nc` (両数) と、`pl` の6番目の要素 (番線ごとの長さ) を追加。古い保存データは、編成=4両・ホーム=4マスとして読み込みます

## 縮尺と実寸 (1マス = 5m)
寸法は `js/02-state.js` の `MPC`(1マスの長さ[m])と `SZ` で決まります。メートルで書いて `mtc()` でマスに換算しているので、数字を変えると線路・ホーム・駅舎・列車が連動して変わります。
| 対象 | 実寸 | マス換算 |
|---|---|---|
| 車両の長さ(連結器まで) | 20m | 4マス (`CP`) |
| 車体の長さ / 幅 | 19.5m / 2.9m | 3.9 / 0.58 |
| 軌間(レールの間隔) | 1.067m | 0.21 |
| 道床の幅 / 枕木の長さ | 3.4m / 2.0m | 0.68 / 0.4 |
| 線路中心からホーム縁 | 1.7m | 0.34 |
| 番線の間隔 | 10m | 2マス (島式ホーム幅 6.6m) |
| ホームの長さ | 2〜10両 = 40〜200m | 8〜40マス |
| 駅舎の奥行き / 長さ | 14m / 最大50m | 2.8 / 最大10マス |
| ホーム高さ / 車高 / 駅舎高さ | 1.1m / 3.6m / 約10m | 3D表示で反映 |
- 両数・ホームの長さは従来どおり「両」で持ち、マスにするときだけ `CP` を掛けています。
- 走行の速さは従来どおり「1両=20秒」(1マス=5秒)です。速度スライダー1あたり 1両/秒 で進みます。
- カーブでは車体も線路に沿って曲がります (長い車両が45°の折れ点を斜めに突っ切らないように)。
- 縮尺が変わったため、保存キーを `rail1/rail2` から `rail3/rail4` に変えました。旧縮尺のデータは読み込まれず、初期配置から始まります。
- 拡大率は 1.5〜160 (1マスの画面上の大きさ px)。初期は 10。レールと道床は拡大率9以上、枕木は30以上で描きます。
